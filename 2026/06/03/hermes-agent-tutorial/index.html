Hermes Agent 安装与使用教程——让你的 AI 助手 24 小时在线

2026-06-03 · 教程

我为什么要装它

说实话，市面上的 AI 助手太多了——Copilot、Cursor、Claude Code、Codex，各有各的好。但有个问题一直困扰我：它们只活在特定 App 里。你在电脑前写代码，它们能帮上忙；你出门了想改个东西、问个事，就只能干等着。

Hermes Agent 解决的就是这个问题。它本质上是一个”跑在你自己服务器上的 AI”，你可以在终端里用、在微信里用、在 Telegram 里用——同一个大脑，随时随地。而且它不是那种只会聊天的 bot，它真的能动你的文件、跑命令、查网页，跟你在电脑前操作没啥区别。

我用了一段时间后觉得这东西值得写篇教程——不是因为多难装，而是它打开的思路值得分享。

环境要求

你不需要什么高配机器。我自己跑在一台 2 核 2G 的轻量云服务器上，完全够用。

  • 操作系统：Linux（Ubuntu/Debian/CentOS 都行），macOS 也支持，Windows 建议走 WSL2
  • Python：3.11+，安装脚本会自动处理，不用你操心
  • Git：用来拉代码

如果你连服务器都没有，本地电脑上也一样跑。

安装——真的就一行命令

跑完你会看到它自动做了三件事：

  1. 检测系统环境，创建虚拟环境
  2. 克隆仓库，安装所有 Python 依赖
  3. 把 hermes 命令注册到你的 PATH

半分钟搞定，没什么坑。唯一需要注意的是：如果你网络不好连 GitHub 慢，挂个代理或者换个镜像源就行。

模型供应商：我选了 DeepSeek。原因是——便宜且聪明。DeepSeek V3 的代码能力跟 Claude 不相上下，但价格便宜一大截。如果你预算充足也可以用 Anthropic（Claude）或者 OpenAI，Hermes 支持 20+ 家供应商，随时可以切。

API Key：在对应平台的后台生成一个就行。把 key 填进去，后续聊天就自动用了。如果你有多个 key（比如 DeepSeek 和 OpenAI 都有），可以在配置文件里加多个，Hermes 会自动轮换，哪个有额度用哪个。

工具集：默认配置就够用。文件读写、终端命令、网页搜索这些核心功能默认都开着。后续如果觉得某些工具不需要，可以随时通过 hermes tools 关掉。

第一次对话

回车之后你就进入了一个交互式终端。跟普通聊天 AI 差不多——你打字，它回复。但区别在于，它能真的做事。

比如你直接说”帮我在当前目录创建一个 Python 项目”，它会自动跑 mkdir、touch、写文件，而不是告诉你”你应该这样做”。

几个我常用的对话命令：

指令 作用
/new 开新会话，刷新上下文
/model 随时切换模型
/undo 当你发现它开始跑偏，撤回上一步
/compress 对话太长了，手动压缩上下文

技能系统——这才是它变聪明的关键

技能（Skills）是我觉得 Hermes 跟其他 Agent 最大的差异点。

简单说：你教它的东西，它能记住并复用。

比如你第一次让它”帮我部署 Hexo 博客到 GitHub Pages”，它可能磕磕绊绊。你在过程中纠正了几次——Token 要这样配、分支名应该是 main 而不是 master、运行命令要加 npx 前缀。搞完之后，你可以让它把这些经验保存成一个技能：

接入聊天平台——这部分我重点讲

前面说了，Hermes 最吸引我的是随时随地能用。核心就是这个 Gateway 功能。

原理

Gateway 是一个常驻后台服务，它在你的服务器上跑着，同时连接多个聊天平台。你在微信发一条消息 → Gateway 收到 → 转发给 Hermes Agent 处理 → 把结果发回你的微信。整个过程你的服务器是”大脑”，聊天平台只是”界面”。

微信自己的坑

  • 微信账号会被风控：别用主力号，容易触发。用一个小号，或者找朋友借一个不活跃的号。刚开始用的前 24 小时尽量少发消息，让它”热身”。
  • 扫码登录偶尔掉线：微信网页版协议不稳定，有时候会莫名其妙断开。我已经习惯了，说一句”帮我重启 gateway”就行。建议配合 cron 做个定时检查。
  • 被封了怎么办：说实话没办法。这是平台政策，不是技术问题。如果真的封了，换号继续。

其他平台

Hermes 还支持 Discord、Slack、WhatsApp、Signal、邮件、短信、钉钉、飞书、企业微信等。配置流程大同小异，hermes gateway setup 向导会一步步引导。同一台服务器可以同时连多个平台，你在微信发了消息，去 Telegram 也能看到回复，因为它们是同一个 Agent。

多模型轮换

我在 .env 里配了 DeepSeek 和 Qwen 两个 key。当 DeepSeek 额度用完，Hermes 自动切到 Qwen——你不用管，它自己搞定。

自定义工具

如果你懂一点 Python，可以自己写工具。Hermes 会读你写的代码，把它变成 Agent 可调用的函数。比如我写了一个”查今天天气”的工具，对话中说”今天出门要带伞吗”，它就会自动调用。

总结

装 Hermes Agent 本身没什么技术门槛，一行命令的事。但装完之后你会发现，你有了一个真正”属于你”的 AI 助手——你的数据在自己服务器上，你的偏好它记得住，你的工作流它能学习。

用一个比喻收尾：ChatGPT 像是你在咖啡店找人临时帮忙，Hermes 像是你雇了一个记得你所有习惯的私人助理。

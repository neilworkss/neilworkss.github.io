Hermes Agent 安装与使用教程——让你的 AI 助手 24 小时在线

2026-06-03 · 教程

我为什么要装它

说实话，市面上的 AI 助手太多了——Copilot、Cursor、Claude Code、Codex，各有各的好。但有个问题一直困扰我：它们只活在特定 App 里。你在电脑前写代码，它们能帮上忙；你出门了想改个东西、问个事，就只能干等着。

Hermes Agent 解决的就是这个问题。它本质上是一个”跑在你自己服务器上的 AI”，你可以在终端里用、在微信里用、在 Telegram 里用——同一个大脑，随时随地。而且它不是那种只会聊天的 bot，它真的能动你的文件、跑命令、查网页，跟你在电脑前操作没啥区别。

我用了一段时间后觉得这东西值得写篇教程——不是因为多难装，而是它打开的思路值得分享。

环境要求

你不需要什么高配机器。我自己跑在一台 2 核 2G 的轻量云服务器上，完全够用。

  • 操作系统：Linux（Ubuntu/Debian/CentOS 都行），macOS 也支持，Windows 建议走 WSL2
  • Python：3.11+，安装脚本会自动处理，不用你操心
  • Git：用来拉代码

如果你连服务器都没有，本地电脑上也一样跑。

安装——真的就一行命令

跑完你会看到它自动做了三件事：

  1. 检测系统环境，创建虚拟环境
  2. 克隆仓库，安装所有 Python 依赖
  3. 把 hermes 命令注册到你的 PATH

半分钟搞定，没什么坑。唯一需要注意的是：如果你网络不好连 GitHub 慢，挂个代理或者换个镜像源就行。

第一次对话

回车之后你就进入了一个交互式终端。跟普通聊天 AI 差不多——你打字，它回复。但区别在于，它能真的做事。

比如你直接说”帮我在当前目录创建一个 Python 项目”，它会自动跑 mkdir、touch、写文件，而不是告诉你”你应该这样做”。

几个我常用的对话命令：

指令 作用
/new 开新会话，刷新上下文
/model 随时切换模型
/undo 当你发现它开始跑偏，撤回上一步
/compress 对话太长了，手动压缩上下文

技能（Skills）是我觉得 Hermes 跟其他 Agent 最大的差异点。

接入微信——让你的 AI 住在微信里

这节是整篇教程最重要的部分，也是 Hermes 最打动我的功能——把 AI 助手接到微信里，像跟朋友聊天一样使用。

原理

Hermes 的 Gateway 是一个常驻后台服务，跑在你的服务器上。它的工作很简单：你在微信发一条消息 → Gateway 收到 → 交给 Hermes Agent 处理 → 把结果发回你的微信。对你来说只是发了条微信，但背后你的服务器在读文件、写代码、搜网页。微信是界面，服务器是大脑。

第一步：准备一个微信账号

首先你得有个微信号给 Hermes 用。这里有一个重要建议：不要用你的主力微信号。

原因不是技术限制，而是微信对”非正常人类操作”很敏感——Hermes 可能高频率收发消息，偶尔会触发风控。虽然不至于封号（我用了挺久没被封过），但万一呢？所以搞个小号或者用家人的备用号比较稳妥。

如果实在没有小号，主力号也能用，就是刚开始建议悠着点，别一上来连发几十条。

第二步：配置 Gateway

进入向导后选 weixin，然后跟着提示走。核心步骤就是用你的备用微信号扫码，给 Hermes 授权登录。扫完码终端会显示类似 Weixin: Logged in as xxx 的提示，说明登录成功。

微信使用技巧

私聊 vs 群聊

Hermes 支持私聊和群聊。在群里 @它 就能触发。建议建一个”AI 助手专属群”，只有你和 Hermes，这样聊天记录不会跟其他人混在一起。

设置不同的 profile

如果你想让工作相关的对话和私人对话隔离开，可以创建多个 profile：

每个 profile 有独立的配置、记忆和技能，互不干扰。然后在微信里通过指定的触发方式（比如不同群）绑到不同 profile 上。

发图片和文件

微信里发给 Hermes 的图片它会自动分析，你发个截图问”这段代码什么意思”，它就能看懂。它返回的结果里如果有文件，会自动以附件形式发给你。

Q: 会不会被封号？

我用小号跑了几个月，目前没有被封。几点建议：

  • 刚登录的前几个小时不要高频发消息，给它”暖机”
  • 不要用这个号加太多好友或者发广告
  • 正常使用的话微信一般不会管

Q: 微信平台有什么限制？

主要是消息频率。微信对机器人行为有隐形限速，如果 Hermes 短时间内发太多条消息，可能会被暂时限制。正常使用（几秒一条）完全没问题。

其他支持的平台

除了微信，Hermes 还支持 Telegram、Discord、Slack、WhatsApp、Signal、钉钉、飞书、企业微信等十多个平台。配置方式都一样——hermes gateway setup 选对应平台即可。而且同一个 Gateway 可以同时连多个平台，你在微信发的消息、Telegram 上也能看到回复，因为背后是同一个 Agent 大脑。

多模型轮换

如果你懂一点 Python，可以自己写工具。Hermes 会读你写的代码，把它变成 Agent 可调用的函数。比如我写了一个”查今天天气”的工具，对话中说”今天出门要带伞吗”，它就会自动调用。

总结

装 Hermes Agent 本身没什么技术门槛，一行命令的事。但装完之后你会发现，你有了一个真正”属于你”的 AI 助手——你的数据在自己服务器上，你的偏好它记得住，你的工作流它能学习。

用一个比喻收尾：ChatGPT 像是你在咖啡店找人临时帮忙，Hermes 像是你雇了一个记得你所有习惯的私人助理。

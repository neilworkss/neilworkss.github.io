Hermes Agent 安装与使用教程

2026-06-03 · 教程

什么是 Hermes Agent？

Hermes Agent 是 Nous Research 开源的 AI 智能体框架，可以在终端、聊天平台和 IDE 中运行。它和 Claude Code、OpenAI Codex 属于同一类工具——通过工具调用来与你的系统交互，完成编程、写作、数据分析等各种任务。

Hermes 的独特之处：

  • 🧠 自我进化通过技能（Skills）：每次解决复杂问题后，可以将方法保存为可复用的技能文档，下次自动加载
  • 💾 跨会话持久记忆：记住你的偏好、环境信息、经验教训，不会每次对话都从零开始
  • 🌐 多平台网关：同一个 Agent 能在 Telegram、Discord、Slack、微信、WhatsApp 等 10+ 平台运行
  • 🔄 不限模型供应商：支持 OpenRouter、Anthropic、OpenAI、DeepSeek 等 20+ 家，可随时切换
  • 📦 高度可扩展：支持插件、MCP 服务器、自定义工具、Webhook、Cron 定时任务等

环境要求

  • 操作系统：Linux、macOS、Windows（推荐 WSL2）
  • Python：3.11+（安装脚本会自动处理）
  • Git：用于安装和版本管理

日常使用

基础命令

命令 说明
hermes 启动交互式对话
hermes chat -q "问题" 单次问答
hermes model 切换模型/供应商
hermes doctor 系统健康检查

对话内快捷指令

在对话中使用 / 开头：

指令 作用
/new 开启新会话
/model 模型名 切换模型
/skills 搜索/安装技能
/skill 技能名 加载指定技能
/undo 撤销上次对话
/exit 退出

配置文件位置

文件 路径 说明
主配置 ~/.hermes/config.yaml 所有设置
密钥 ~/.hermes/.env API Key 等敏感信息
技能 ~/.hermes/skills/ 已安装的技能
会话记录 ~/.hermes/state.db SQLite 会话存储
日志 ~/.hermes/logs/ 运行日志

常见问题

Q: 切换模型后不生效？

运行 /reset 开新会话，或者重启 hermes。

Q: 工具不可用？

然后 /reset 重开会话。

Q: API Key 在哪设置？

编辑 ~/.hermes/.env，格式为 API_KEY_NAME=your_key。或者运行 hermes auth 进行交互式认证。
